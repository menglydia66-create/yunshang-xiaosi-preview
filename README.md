# 云上小寺 / Yunshang Xiaosi

A walkable temple in the browser. You don’t need to go anywhere. Open this page, and a quiet visit can begin: walk through the temple, listen to a sutra, sit and breathe. It doesn’t promise mystical results—just a little time, some company, and a chance to come back to yourself. Fortune readings, if you try them, are for reflection and entertainment only.

不必去某个固定场所。打开这个网页，就可以开始一段静心之旅：走进寺院、听经、冥想，也有人轻轻陪伴。它不保证什么神奇效果，只把一段安静的时间还给你，帮你找回自己。求签与读盘仅供娱乐与自我观照。
