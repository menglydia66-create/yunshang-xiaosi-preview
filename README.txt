云上小寺 · 本地预览（名称待定）
================================

这是一个尚未上线的本地预览，请在自己的电脑上打开。不要上传到任何公开网站。

一、推荐打开方式（Windows）

1. 解压本压缩包，进入「prototype」文件夹（若解压后直接看到 index.html，就停在这一层）。
2. 双击「start.bat」。
3. 若已安装 Python，会自动在浏览器中打开 http://127.0.0.1:8080/ 。
4. 用 Chrome 或 Edge 访问。首次载入大约需要几秒，点「入寺」即可漫步。
5. 看完后，在弹出的黑色窗口里按 Ctrl+C 结束本地服务。

若双击 start.bat 提示找不到 Python：
- 可安装 Python 3（安装时勾选 “Add python.exe to PATH”），或
- 在当前文件夹打开终端，执行：  py -m http.server 8080
  然后用浏览器打开 http://127.0.0.1:8080/

二、也可以直接双击 index.html

部分电脑可以这样打开，但 Windows 下用 file:// 直接打开时，角色模型、光照或心经音频有可能被浏览器拦住。若出现黑屏、角色不出现或听经无声，请改用上面的 start.bat。

三、怎么玩

- 行走：W A S D 或方向键；手机可使用左下角摇杆。
- 环视：按住画面拖动；滚轮拉近拉远。
- 镜头是贴身跟拍（第三人称、略偏过肩），走路时能看到主角全身动作。
- 底部按钮：
  打坐　走到大殿蒲团坐下（再点一次起身）
  听经　播放今日经文（每日轮换一篇）。有诵读录音时同步滚屏；默读日则按从容节奏缓缓滚动
  冥想　4 秒吸气、6 秒呼气的引导，可选 3 / 5 / 10 分钟
  礼拜　合十鞠躬
  点灯　点亮庭院中未亮的灯笼，并在莲池放一盏河灯。也可直接点击庭院里的灯笼或石灯；靠近或悬停时会提示「点亮这盏灯笼」。点击香炉可续香
  求签 · 每日一启　在求签处看今日运势
- 右上角可切换「画质 · 高 / 流畅」，以及声音开关。点「关于」可查看素材来源。

四、求签 · 算命（仅预览）

- 求签面板有四个页签：每日一签、读盘、合盘、AI问答。非会员先看到锁定预告。
- 打开「模拟会员（仅预览）」后可使用全部功能。没有支付，也没有真实账号。
- 每日一签：每天可求一支签，结果按日期保存在本机浏览器中；同一天再次打开会显示「今日已启，明日再来」。
- 读盘：填写公历或农历出生日期与时辰（时辰可留空），在本机排出四柱八字，并给出气质、事业学业、感情、身心与近日提醒。解读语气温和，不作吉凶断言。
- 合盘：填写两个人的出生信息，看五行与日柱关系，给出相处与沟通提醒，不是判定「合不合」。
- AI问答：结合已保存的盘面，在本机回答你的问题（也可用常用问题）。不联网、不调用外部模型；涉及医疗、投资或关系去留时，会明确不代替专业判断。
- 出生信息、签文与会员开关都只保存在本机浏览器，不会上传。可在「关于」里一键清除。
- 全部内容仅为娱乐与自我观照，不构成专业命理、医疗、财务或情感承诺。

本预览不收集个人信息，也不连接到任何服务器。
